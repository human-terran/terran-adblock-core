### How to Subscribe

**Terran Shield / uBlock Origin / AdGuard Extension:**
1. Go to **Filters** -> **Custom Subscriptions** (or **My filters** -> **Subscribe**)
2. Paste the **Terran-Core** Raw URL above (already built into **Terran Shield** as the default compact core filter)

**AdGuard DNS (Cloud):**
1. Go to **User Rules** -> **Import** for **blocklist-standard** (415 rules) or **blocklist-pro** (241 rules) — Personal plans allow up to 1,000 User Rules
2. Built-in DNS Blocklists (**OISD**, **HaGeZi**, **AdGuard DNS**) can be enabled alongside without using your User Rules quota
