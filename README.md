### How to Subscribe

**AdGuard DNS:**
1. Go to **DNS Blocklists**
2. Add the desired Raw URL above
3. Enable the list

**uBlock Origin / AdGuard Extension:**
1. Go to **My filters** → **Subscribe**
2. Paste the Raw URL

**Recommendation:**  
Start with **Terran Custom**. Switch to **Terran-PRO** if you want stronger blocking.
