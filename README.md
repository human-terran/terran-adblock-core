### How to Subscribe

**AdGuard DNS:**
1. Go to **DNS Blocklists**
2. Add the desired Raw URL above
3. Enable the list

**Terran Shield / uBlock Origin / AdGuard Extension:**
1. Go to **Filters** -> **Custom Subscriptions** (or **My filters** -> **Subscribe**)
2. Paste the Raw URL
