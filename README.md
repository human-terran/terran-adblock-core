### How to Subscribe

**Terran Shield / Single Safari Extension / AdGuard Extension:**
1. Use **Terran-Core** (`~701 KB`) for ultra-compact DNS/tracker privacy, **OR** use **Terran-Core-Max** (`132,021` compiled Safari rules) if you want Ads + Trackers + Telemetry + Cookie Banners + Popups + Social Widgets + Malware in **one single Safari extension** (under the 150,000-rule ceiling).

**AdGuard DNS (Cloud):**
1. Go to **User Rules** -> **Import** for **blocklist-standard** (415 rules) or **blocklist-pro** (241 rules) — Personal plans allow up to 1,000 User Rules.
2. Enable built-in DNS Blocklists (**OISD**, **HaGeZi**, **AdGuard DNS**) alongside without using your User Rules quota.
